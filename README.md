# ENGLISH LEARNING INSTITUTE - Modern Responsive Website

A modern, premium, professional, and fully responsive website for **ENGLISH LEARNING INSTITUTE**, built with pure HTML5, Vanilla CSS3, and JavaScript for lightning-fast loading speed and high aesthetic appeal.

---

## 🌟 Key Features

1. **Hero Section**:
   - Institute Name: **ENGLISH LEARNING INSTITUTE**
   - Headline: *"Learn English. Speak Confidently. Build Your Future."*
   - Direct CTA buttons: **"Enquire Now"** & **"Join Now / View Courses"**
   - High-resolution English learning visual with floating badges (*100% Practical Speaking*, *Certified Mentors*)
   - Quick statistics counter (12,000+ Trained Graduates, 98% Fluency Rate, 100% Practical Drills)

2. **Courses Section (Start at Your Level - 6 Courses)**:
   - **Spoken English** (Basic and Intermediate - Practical speaking, interactive activities, GD & public speaking)
   - **Advanced Level** (Critical thinking, debates, advanced sentence formation, thinking in English)
   - **Pre Basic** (Reading & writing practice, word formation, everyday vocabulary, simple sentences)
   - **Kids Package** (Listening & speaking, daily conversation, activity-oriented learning, language games)
   - **Intermediate and Advanced** (Natural expressions, pronunciation, fluent communication, public speaking)
   - **Business English** (Professional situations, intonation & speaking rhythm, advanced vocabulary)

3. **WhatsApp Enquiry Section (Strictly Two Inputs)**:
   - Input 1: **Name**
   - Input 2: **Mobile Number**
   - Mobile number validation (checks 10-digit format and highlights errors)
   - Real-time pre-filled message preview
   - **"Send Enquiry on WhatsApp"** button generating:
     ```text
     New Enquiry – ENGLISH LEARNING INSTITUTE
     Name: <User Name>
     Mobile: <User Mobile>
     I am interested in joining the English learning course.
     ```

4. **Our Key Features**:
   - 8 Core Student Benefits (Level-based training, 15/batch, 2-hr daily classes, flexible timing, no age barrier, weekend batches, personal training).
   - Real mentor-student coaching visual.

5. **Student Reviews & FAQ**:
   - Real student testimonials with 5-star ratings.
   - Interactive FAQ accordion for common queries.

6. **Footer & Quick Navigation**:
   - Institute branding & about statement
   - Quick links & course directory
   - Direct contact details (phone, email, campus address, hours)
   - WhatsApp quick enquiry button
   - Copyright © 2026 ENGLISH LEARNING INSTITUTE

7. **Floating WhatsApp Chat Button**:
   - Fixed bottom-right quick chat action with hover tooltip.
